# 🍳 ผัดไทยกุ้งสด (Pad Thai)

โปรเจกต์ฝึกเขียนสูตรอาหารแรกบน GitHub

### 🛒 วัตถุดิบ
- [ ] เส้นจันท์ 150 กรัม
- [ ] กุ้งสด 5-6 ตัว
- [ ] ถ้าหู้เหลืองหั่นเต๋า 2 ช้อนโต๊ะ
- [ ] ถั่วงอกและใบกุยช่าย
- [ ] น้ำซอสผัดไทย 3 ช้อนโต๊ะ

### 👩‍🍳 ขั้นตอนการทำ
1. ผัดเต้าหู้และกุ้งสดในกระทะให้พอสุก ตักกุ้งพักไว้
2. ใส่เส้นจันท์และน้ำซอสลงไปผัดจนเส้นเหนียวนุ่ม
3. ตอกไข่ใส่ลงไป ขยี้ให้สุก แล้วตลบเส้นมากลบไข่
4. ใส่ถั่วงอก ใบกุยช่าย และกุ้งสดลงไปผัดให้เข้ากัน พร้อมเสิร์ฟ

```python
# โค้ดภาษา Python สำหรับคำนวณราคาขายผัดไทย
cost = 35          # ต้นทุนวัตถุดิบ (บาท)
profit_margin = 20 # กำไรที่ต้องการ (บาท)
selling_price = cost + profit_margin
print("ราคาขายผัดไทยกุ้งสด คือ:", selling_price, "บาท")
```
